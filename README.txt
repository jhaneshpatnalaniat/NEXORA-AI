NEXORA AI — College Project
===========================

FILES
- index.html : all page sections and content
- style.css  : visual design, responsive layout and animations
- script.js  : interactive cards, detail panel, filters, menu and form

RUN LOCALLY
1. Extract the NEXORA-AI folder.
2. Open index.html in Google Chrome.
3. Keep all three files in the same folder.

GITHUB PAGES
1. Create a GitHub repository.
2. Upload index.html, style.css and script.js to the repository root.
3. In Settings > Pages, choose Deploy from a branch and select the main branch / root.
4. Save and open the published URL.

NOTES
- Product names and descriptions are fictional educational concepts.
- The contact form only validates locally; it does not send or store messages.
- Google Fonts are optional; fallback fonts are included if internet access is unavailable.
- No API keys, frameworks, build tools or backend are required.
